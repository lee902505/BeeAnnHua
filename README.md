3. 本月五张：月初 → 月中前 → 月中后 → 月底 → 整体建议

### 抽牌规则
- 78 张牌中无放回随机抽取，同一牌阵不会抽到重复实体牌。
- 每张牌独立判定正位 / 逆位，各 50%。
- 使用浏览器 Crypto API 进行随机抽取。

### 组合判读引擎
不会只把 3 张或 5 张的牌义串在一起，而会同时读取：
- 每张牌所在的位置
- 正位 / 逆位
- 用户选择的问题主题
- 大阿尔克那占比
- 正位 / 逆位比例
- 花色是否集中
- 对应元素是否集中
- 从第一张到最后一张的发展顺序

牌义骨架采用 Rider-Waite-Smith 传统象征体系；本项目的中文解读与组合文字均重新撰写，不复制单一网站的现成占卜结果。
