# V0.13.4 — 偷菜系统＋蔬果盲盒

本版在 V0.13.3 的好友拜访基础上开放真实偷菜，并在商店新增「蔬果盲盒」。

## 新功能

- 好友成熟作物可以直接点击偷菜。
- 每次随机偷 1～3 个；同一位好友对同一轮作物只能偷一次；地主永远至少保留 1 个。
- 偷菜由 Supabase RPC 原子验证，不能直接从前端修改好友农场。
- 偷到的作物会直接加入自己的云端背包，并立即同步到本机。
- 好友拜访画面会标记「偷菜 1–3 / 已偷过 / 保底 1」。
- 商店新增 `🎁 蔬果盲盒`：5 金币 / 个，Lv.1 即可购买，固定成长 4 小时。
- 盲盒成熟前不揭晓；成熟时随机变成红萝卜、小麦、玉米、番茄、草莓、南瓜、葡萄或星辰果之一，每盒收成 1 个。
- 稀有作物概率较低；盲盒作物因产量只有 1 个，不开放偷取，符合地主保底规则。

## Supabase

V0.13.4 需要在 SQL Editor 额外执行：

`supabase/migrations/20260924_006_farm_steal.sql`

执行成功应显示 `Success. No rows returned`。既有 003、004、005 migration 仍须已完成。

## 测试建议

1. 用 A 玩家种普通作物并等成熟。
2. B 玩家与 A 成为好友后拜访 A 农场。
3. 点成熟作物，确认随机取得 1～3 个并进入 B 的背包。
4. B 再点同一轮作物，应显示已经偷过。
5. 多位好友连续偷取时，A 的该格永远至少保留 1 个。
6. 商店购买蔬果盲盒，确认价格为 5 金币、成长时间固定 4 小时。
