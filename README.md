# 星辰日记 Web V0.7.1

## 本版目标
V0.7 为塔罗模组的进阶功能版本，不新增任何图片素材，继续使用既有 78 张牌与 `CardBacks.jpg`。

## 新增功能

### 1. 问题输入
- 玩家可输入最多 160 字的实际问题。
- 问题会显示在抽盘结果上，并参与最终组合文案的语境。
- 留空也可占卜，会依「综合 / 感情 / 事业 / 财运 / 学业」做一般指引。
- 对时间型问题与是非型问题加入解释提醒，避免把塔罗硬解释成固定日期或绝对二元答案。

### 2. 感情关系牌阵（5 张）
位置：
1. 我的状态
2. 对方状态
3. 关系核心
4. 主要阻碍
5. 发展建议

组合解读会区分「双方状态」与「关系本身」，不会把某一张牌直接当成另一方内心的绝对证明。

### 3. 二选一牌阵（5 张）
位置：
1. 目前状态
2. 选项 A
3. A 的发展
4. 选项 B
5. B 的发展

- 可填写选项 A / B 名称。
- 结果会分别比较两条路线的推进、阻力与发展方式。
- 不做简单的「系统替玩家决定哪一个一定比较好」，而是把两条路的差异讲清楚。

### 4. 进阶组合判读
除 V0.6 已有的大阿尔克那、正逆位、花色、元素与牌面顺序外，新增：
- 宫廷牌集中
- 多张 Ace
- 多张 10
- 相同数字重复
- 连续数字
- 相邻大阿尔克那连续出现
- 前后段逆位变化（先卡后松 / 后段阻力增加）
- 元素缺失与不平衡
- 感情关系牌阵专用故事逻辑
- 二选一牌阵专用双路线比较逻辑

### 5. 翻牌体验
- 抽盘后先只显示牌背。
- 必须从第一张开始依序翻牌。
- 正位 / 逆位在翻开后才揭晓。
- 每张牌翻开后才显示该牌的牌意、主题解读与提醒。
- 所有牌全部翻开后，才显示完整「整体组合解读」。

## 保留功能
- 78 张牌无放回随机抽取
- 每张牌 50% 正位 / 50% 逆位
- Crypto API 随机
- 单张指引
- 本周指引
- 本月指引
- 综合 / 感情 / 事业 / 财运 / 学业
- 回到顶部 / 返回首页
- 每日运势 60 支籤
- 简体 / 繁体 / English 首页语言记忆

## 素材策略
本版不制作任何新增图片。正式 UI 背景、籤筒、星座视觉与其他插图统一延后到核心功能完成、准备接入 Supabase 后台与 Bark 前处理。

## 下一步
先测试 V0.7：
1. 问题输入在 PC / 手机是否舒服。
2. 5 种牌阵是否都能正常抽取。
3. 翻牌顺序是否正确。
4. 正逆位在翻开前是否不会提前泄露。
5. 所有牌翻完后组合解析是否才出现。
6. 感情牌阵与二选一结果是否符合阅读直觉。


## V0.7.1 介面與通用性修正
- 牌阵选择卡片不再显示 1 / 3 / 5 数字。
- 统一改用既有 `CardBacks.jpg` 的小型塔罗牌背图示，不新增图片素材。
- 「感情关系牌阵」改名为「关系互动指引」。
- 「二选一牌阵」改名为「二选一指引」。
- 「关系互动指引」取消自动切换到感情类别，五种问题方向皆可使用。
- 第二位置改为动态语境：
  - 综合：外在环境
  - 感情：对方
  - 事业：合作方／工作环境
  - 财运：外在资源／市场环境
  - 学业：学习环境／外在条件
- 关系类组合解读同步改成通用互动逻辑，不再把五张牌写成只适用于爱情关系。
