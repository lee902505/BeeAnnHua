# 星辰日记 Web V0.10.4

## 本版目标：本命盘数据层封版

V0.10.4 不改动天文位置、Placidus 宫位、逆行或原有五大主要相位计算公式。
本版重点是把已经算出的本命盘资料进一步结构化与交叉解读，为后续 V0.11「完整解析报告」准备可复用的数据层。

### 1. 主要相位深度解读

十颗主要星体共有 45 组不同的两两组合，本版为全部 45 组建立独立互动主题。

每一个实际成立的主要相位现在会显示：
- 两颗星各自代表什么
- 这两颗星组合时的核心主题
- 合相 / 六分 / 四分 / 三分 / 对分各自怎样改变互动
- 可发挥优势
- 容易卡住
- 整合方向
- 实际 orb 与紧密程度

因此「月亮对分金星」与「太阳对分土星」不会再只得到同一种对分说明。

### 2. 命主星 Chart Ruler

有准确出生时间时，根据上升星座取得命主星，并显示：
- 命主星是哪一颗
- 命主星星座与度数
- 命主星落宫
- 逆行状态
- 命主星最紧密的主要相位
- 命主星如何成为整张盘的实际出口

天蝎 / 水瓶 / 双鱼会同时显示：
- 现代主星
- 传统主星参考

不会把不同占星流派强行说成唯一答案。

### 3. 大型格局

本版新增独立 `astrology-synthesis.js`，在不改变原相位计算的前提下，从实际相位网络检测：

- 星座群星（3+ 主要星体）
- 宫位群星（3+ 主要星体）
- 大三角 Grand Trine
- T 三角 T-Square
- 大十字 Grand Cross
- 风筝 Kite
- 神秘矩形 Mystic Rectangle

规则：
- 大型格局只使用本站已经计算的五大主要相位。
- Grand Cross 内重复的 T-Square 不重复列出。
- Kite 内含的 Grand Trine 不再重复列出。
- 不依星座大概位置硬凑格局，必须有实际相位成立。

### 4. 完整人格整合

「完整摘要」从原本 3 个简短区块扩展为：

- 核心人格骨架
- 情绪与安全感
- 思考与沟通
- 关系与亲密
- 行动与压力
- 事业与人生方向
- 主要能量模式
- 主要成长课题
- 整合建议

这些内容会同时读取：
太阳 / 月亮 / 上升、行星落座、落宫、相位、元素、模式、命主星与大型格局。

### 5. 架构

新增：
- `data/astrology/natal-synthesis.json`
- `js/astrology-synthesis.js`

这两个文件会成为之后 V0.11「完整星盘解析报告」的基础资料层，不需要重新从画面文字反向解析。

### 6. 保留

V0.10.3.9 的功能全部保留：
- 阳历 / 阴历
- 本地阴历算法与闰月
- 手机阴历日期表

- Bark

# 星辰日记 Web V0.10.3.6

## 农历系统本地化重写

V0.10.3.5 实机测试发现：
- 年份正常
- 月份正常
- 选择普通月份后，日期仍被误判为不存在

### 根本原因
第三方 `solarlunar` 的浏览器 UMD 版本与我们之前使用的验证方式存在回传行为差异。
使用「农历 → 阳历 → 再转回农历」作为 UI 日期生成条件，会导致 Safari 上正常月份被错误判断为无效。

### V0.10.3.6
不再依赖外部农历 CDN。

新增：
`js/lunar-calendar.js`

内建：
- 1900–2100 农历大小月资料
- 每年闰月

- 年
- 月
- 日
- 是否闰月

- 该年闰哪一个月
- 没有闰月时不显示任何错误闰月

- 闰月 29 天或 30 天

7. 下方立即显示「换算阳历」

- 不存在的闰月

# 星辰日记 Web V0.10.1

## 新增：Stellar Compatibility Index 合拍指数

V0.10.1 在 V0.10 两人合盘上新增 0–100 的合拍指数。

### 五个分项
- 情绪默契
- 沟通理解
- 亲密吸引
- 长期稳定
- 成长互补

### 不同关系类型使用不同权重
恋爱／暧昧、情侣、夫妻／长期伴侣、朋友、工作伙伴不会使用同一套百分比。

例如情侣模式：
- 情绪 25%
- 沟通 20%
- 吸引 25%
- 稳定 20%
- 成长 10%

工作伙伴模式则提高沟通与稳定的比例。

### 计分不是简单「好相位 +1 / 坏相位 -1」
每个跨盘相位会依：
1. 行星组合重要度
2. 相位性质
3. 实际 orb 紧密度
4. 所属分项
5. 关系类型权重

共同计算。

### Orb
越接近 0° 的精确相位，贡献越强；
越靠近当前相位容许度边缘，影响会平滑下降。

### 合相
合相不会自动加分。
例如：
- 太阳／月亮、月亮／金星、金星／火星等，通常可增加协调或吸引。
- 月亮／冥王星、月亮／火星、土星与个人星体等，会依「情绪、吸引、稳定、成长」不同分项分别处理。

### 0–100 的意义
合拍指数表示「占星互动的自然顺畅程度与需要磨合的压力」，
不是：
- 恋爱成功率
- 婚姻概率
- 会不会分手的预测
- 现实关系结果保证

### UI
- 合盘结果顶部新增大号 0–100 指数
- 显示五个分项
- 显示当前关系类型的五项权重
- 新增可展开「计分依据」

# 星辰日记 Web V0.8

## 本版目标：星座测算核心

V0.8 正式加入出生资料计算，先完成西洋占星最常使用的三个核心位置：

- ☉ 太阳
- ☽ 月亮
- ASC 上升

本版仍不新增任何图片素材。

## 计算方式

### 天文计算
- 热带黄道（Tropical Zodiac）
- Astronomy Engine JavaScript 2.1.19
- 太阳：出生瞬间的视地心真黄经
- 月亮：出生瞬间的地心真黄道经度
- 上升：Greenwich Apparent Sidereal Time + 出生地经度 → 当地恒星时，再配合纬度与黄赤交角计算东方地平线与黄道交点
- 出生地时区使用 IANA timezone，并通过浏览器 Intl 处理历史夏令时

### 出生时间未知
- 太阳、月亮以出生地当地 12:00 作为近似计算点
- 额外检查当地 00:00 与 23:59 的月亮星座
- 如果月亮当天跨星座，会明确显示两个可能星座
- 上升不猜测、不使用「每两小时一个星座」查表，直接显示无法计算

## V0.8 页面输入

- 出生时间
- 出生城市
- 不知道出生时间
- 手动纬度 / 经度 / IANA 时区（城市列表找不到时使用）
