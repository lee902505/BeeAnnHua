## Bark
已使用用户提供旧 HTML 中原有的 Bark Key进行本机测试接入。

已接功能：
1. 每日运势
2. 塔罗完整结果
3. 本命星盘

使用 Bark 官方 POST JSON 方式。

### 每日运势
仅当天第一次产生新签时发送。
内容包含玩家、日期、签号、等级、关键词、分数、总览、感情、事业、财运、人际、建议与幸运资料。

### 塔罗

# 星辰日记 Web V0.10.1

## 新增：Stellar Compatibility Index 合拍指数

V0.10.1 在 V0.10 两人合盘上新增 0–100 的合拍指数。

### 五个分项
- 情绪默契
- 沟通理解
- 亲密吸引
- 长期稳定
- 成长互补

### 不同关系类型使用不同权重
恋爱／暧昧、情侣、夫妻／长期伴侣、朋友、工作伙伴不会使用同一套百分比。

例如情侣模式：
- 情绪 25%
- 沟通 20%
- 吸引 25%
- 稳定 20%
- 成长 10%

工作伙伴模式则提高沟通与稳定的比例。

### 计分不是简单「好相位 +1 / 坏相位 -1」
每个跨盘相位会依：
1. 行星组合重要度
2. 相位性质
3. 实际 orb 紧密度
4. 所属分项
5. 关系类型权重

共同计算。

### Orb
越接近 0° 的精确相位，贡献越强；
越靠近当前相位容许度边缘，影响会平滑下降。

### 合相
合相不会自动加分。
例如：
- 太阳／月亮、月亮／金星、金星／火星等，通常可增加协调或吸引。
- 月亮／冥王星、月亮／火星、土星与个人星体等，会依「情绪、吸引、稳定、成长」不同分项分别处理。

### 0–100 的意义
合拍指数表示「占星互动的自然顺畅程度与需要磨合的压力」，
不是：
- 恋爱成功率
- 婚姻概率
- 会不会分手的预测
- 现实关系结果保证

### UI
- 合盘结果顶部新增大号 0–100 指数
- 显示五个分项
- 显示当前关系类型的五项权重
- 新增可展开「计分依据」
- 继续保留完整跨盘相位解析

# 星辰日记 Web V0.8

## 本版目标：星座测算核心

V0.8 正式加入出生资料计算，先完成西洋占星最常使用的三个核心位置：

- ☉ 太阳
- ☽ 月亮
- ASC 上升

本版仍不新增任何图片素材。

## 计算方式

### 天文计算
- 热带黄道（Tropical Zodiac）
- Astronomy Engine JavaScript 2.1.19
- 太阳：出生瞬间的视地心真黄经
- 月亮：出生瞬间的地心真黄道经度
- 上升：Greenwich Apparent Sidereal Time + 出生地经度 → 当地恒星时，再配合纬度与黄赤交角计算东方地平线与黄道交点
- 出生地时区使用 IANA timezone，并通过浏览器 Intl 处理历史夏令时

### 出生时间未知
- 太阳、月亮以出生地当地 12:00 作为近似计算点
- 额外检查当地 00:00 与 23:59 的月亮星座
- 如果月亮当天跨星座，会明确显示两个可能星座
- 上升不猜测、不使用「每两小时一个星座」查表，直接显示无法计算

## V0.8 页面输入
- 出生日期
- 出生时间
- 出生城市
- 不知道出生时间
- 手动纬度 / 经度 / IANA 时区（城市列表找不到时使用）

## 内置城市
V0.8 内置台湾、中国大陆、香港、澳门、日本、韩国、东南亚、北美、欧洲、澳洲部分常用城市。

## 解读资料
解读不是复制单一网站，采用传统西洋本命占星的共同定义重新撰写。
主要交叉参考：
- Astrodienst / Astro.com
- Cafe Astrology
- Astrology.com

详细记录见：
`data/astrology/SOURCES.md`
