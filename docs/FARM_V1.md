# 星辰農場 V1（V0.13.0）

## 本版範圍

這一版先完成單人農場核心循環，不假裝多人功能已完成：

`種植 → 真實時間成長 → 收成 → 背包 → 出售 → 金幣 / EXP → 升級 → 解鎖土地與作物`

資料以瀏覽器 `localStorage` 的 `xingchen-farm-v1` 作為離線備援，V0.13.0 起可同步到 Supabase 私人 `farm_saves` 雲端存檔。排行榜、好友、拜訪與偷菜仍需要伺服器端可信運算，因此暫不直接使用這份 client-authoritative 存檔做公開排行。

## 初始設定

- 金幣：100
- 等級：Lv.1
- EXP：0 / 100
- 初始開放土地：6 / 20
- 新手種子：紅蘿蔔 ×3、小麥 ×2

## EXP 曲線

前期升級較快，之後逐步增加需求。第一級需要 100 EXP，新手任務總共可提供 100 EXP，因此完成第一次播種、收成、出售流程即可自然跨入 Lv.2。

## 下一階段多人系統

V0.13.0 已先接上 Supabase 私人雲端存檔；下一階段會把公開經濟與社交資料拆成伺服器可信結構，並由 RPC / Edge Function 驗證：

- `farm_profiles`：等級、EXP、金幣
- `farm_plots`：20 格土地與種植時間
- `farm_inventory`：種子、農作物、道具
- `farm_friends`：好友關係
- `farm_steals`：偷菜紀錄與防重複偷取
- 任務／排行榜需要的統計資料

好友偷菜規則預定：每次隨機 1～3 個，同一好友同一成熟週期只能偷一次，地主至少保留 1 個。

## V0.12.1 視覺更新

- 農場主場景改用正式 2D 插畫背景：農舍、山丘、風車、海岸與大片草地。
- 20 格農地改用透明農田插畫素材，不再使用 CSS 棕色矩形底板。
- 農地仍維持西北 → 東南排列；已解鎖土地為正常土色，未解鎖土地以同一素材灰化顯示。
- 圖片已轉為 WebP 供網頁載入，維持原畫風並大幅降低下載大小。


### V0.12.6 视觉交互
- 主场景移除 MY FIELD 信息条。
- 20 格土地采用更紧密的西北→东南连片排列。
- 桌机悬停农田时向上轻跳，作为当前选中反馈。


## V0.12.6 田地排列微調
- 20 格農田改為更接近連續斜向田區：同列土地略微互相銜接，列與列減少過度重疊。
- 保留西北 → 東南排列。
- 桌機 hover 時單格上浮 12px，並提高層級與亮度，清楚表示目前指向的農地。


## V0.12.9 批量種植

- 選擇作物後新增數量選擇器，可用 `− / ＋`、拖曳滑桿或「全部」決定本次種植格數。
- 可種上限 = `min(持有種子數, 已開放空地數)`。
- 從指定空地開始時會優先種該格，再沿西北 → 東南順序填入其他空地；從背包直接種植則從第一個可用空地開始。
- 背包種子新增「種植」入口。
- 批量播種採逐格短動畫，不會瞬間一次變更所有農地。


## V0.13.0 一鍵收穫與雲端存檔

- 主場景新增「一鍵收穫」按鈕；成熟格數大於 0 時亮起並顯示數量。
- 一鍵收穫會逐格做短動畫，最後一次結算各作物數量與總 EXP。
- 新增 `public.farm_saves` 私人雲端存檔；RLS 只允許 `auth.uid() = user_id` 的玩家存取。
- 初次接雲端時：已有本機農場就上傳；新裝置若已有雲端存檔則自動還原；不同 Supabase 使用者不互相覆蓋。
- localStorage 保留作為離線備援，SQL 尚未部署時農場仍能正常單機遊玩。
- `farm_saves` 暫不作為排行榜可信來源；多人經濟會在下一階段改成伺服器端 RPC / Edge Function 驗證。
