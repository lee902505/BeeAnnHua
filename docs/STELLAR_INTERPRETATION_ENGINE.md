# V0.11.0 — Stellar Interpretation Engine

本版把原先「逐项解释星盘」升级为**本地规则式长篇整合报告**。不接 OpenAI API、不产生额外 API 费用，也不把任何出生资料发送到外部 AI 服务。

## 核心原则

1. **天文计算与文字解释分离**  
   行星、宫位、ASC / MC、相位继续完全由既有 Astronomy Engine + 本项目算法负责。报告引擎只读取已经计算好的结构化星盘，不重新计算天体位置。

2. **先找主轴，再写文章**  
   报告不会平均解释十颗行星。它会先综合：
   - 太阳、月亮、上升
   - 命主星
   - 行星落座 / 落宫
   - 元素与模式分布
   - 角宫强调
   - 紧密相位
   - 逆行
   - 群星与主要大型格局

3. **主题权重排序**  
   七个主题分别计算相对强调程度：核心人格、情绪安全感、思考表达、关系亲密、行动压力、事业方向、成长整合。分数只代表**同一张命盘里的相对强调**，不是人格优劣或命运分数。

4. **组合优先于单项**  
   例如感情会同时读取月亮、金星、火星、第 5 / 7 / 8 宫与相关紧密相位，而不是只输出「金星某星座」的单项说明。

5. **出生时间未知时自动降权**  
   Unknown time 模式不会把 ASC、MC、宫位或命主星当成确定依据，避免产生伪精确结论。

## 文件

- `js/stellar-interpretation-engine.js`：本地整合与长篇报告生成器。
- `data/astrology/stellar-interpretation-engine.json`：主题权重、标签与方法说明。
- `pages/astrology.html`：新增「完整星辰深度报告」入口与报告容器。
- `css/style.css`：报告专属桌面 / 手机视觉样式。

## V0.11.0 报告结构

1. 先说结论
2. 核心人格与外在方式
3. 情绪与安全感
4. 思考、学习与表达
5. 感情、吸引与亲密关系
6. 行动、压力与隐藏驱力
7. 事业、价值感与人生方向
8. 命盘里最明显的拉扯
9. 最值得发挥的优势
10. 长期成长方向
11. 给这张命盘的一句话

## 隐私与成本

- 不需要 OpenAI API Key。
- 不调用外部生成式 AI。
- 不增加 OpenAI API 费用。
- 同一张星盘使用相同规则，输出逻辑稳定。
- 报告仍属于传统西洋占星的象征性解读，不是科学人格诊断或未来预测。
