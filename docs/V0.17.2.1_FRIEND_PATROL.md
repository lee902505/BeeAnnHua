# V0.17.2.1 农友巡田快捷导航

本版为 V0.17 系列最后一项好友 UX 收尾。

## 玩家操作
- 好友农场底部可直接切换上一位、下一位。
- 「下一个可互动」会跳到下一位仍有成熟可偷、虫害或可助力作物的农友。
- 「好友列表」直接返回好友分页，并尽量定位到刚刚巡查的农友。
- 好友卡片显示「今日已拜访」。
- 手机版巡田控制列会 sticky 在拜访画面底部。

## 数据与流量
导航使用当前已载入的 `get_farm_friends_v3()` 概览资料决定顺序；切换农友只读取目标真人好友的最新农场（NPC 为本地 lazy simulation），不会重新刷新完整好友概览。

本版无数据库 schema/RPC 变更，因此不需要 SQL migration。
