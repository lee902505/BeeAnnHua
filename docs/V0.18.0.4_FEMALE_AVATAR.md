# V0.18.0.5 — Default Female farm owner

## Added
- `images/farm/avatar/default-female.png`
- Player profile gender now selects the matching default avatar art automatically.
- Character preview and outfit thumbnail use the same gender-aware sprite selection.

## Locked avatar sprite standard
From this version onward, farm-owner outfit sheets should use this fixed layout:

- Canvas: **1024 × 2048 px**
- Layout: **2 columns × 4 rows**
- Frames: **8**
- Cell: **512 × 512 px**
- Format: **PNG RGBA with real transparency**
- Character center in each cell: **X = 256 px**
- Feet / ground anchor: **Y = 467 px**
- Default visual character height: approximately **417 px**
- Top transparent safety space: approximately **50 px**
- Idle order: Frame 1 → 8 → Frame 1

The male and female default sheets now follow the same frame geometry so CSS sizing can remain identical.

No database migration is required.
