# V0.18.0.5 — Farm scene avatar gender sync fix

## Fixed

When the player profile was changed to female, the character-management modal correctly used the female sprite, but the farm-scene owner at the bottom-right could remain male.

Cause: the farm scene uses a static `.farm-avatar-sprite` element. `renderFarmAvatar()` updated `data-avatar-gender` only on the outer `#farmOwnerAvatar` button, while the gender-specific CSS selector expected the attribute on the sprite itself.

## Change

- `renderFarmAvatar()` now mirrors the resolved gender and outfit onto the inner `.farm-avatar-sprite`.
- CSS also accepts the outer farm-owner gender as a defensive fallback.
- No save migration or Supabase migration is required.
