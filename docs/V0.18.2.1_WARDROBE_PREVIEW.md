# V0.18.2.1 — 衣橱未拥有时装预览

## 目标

让玩家在尚未拥有某件已开放时装时，也能先在「我的角色」里查看穿上后的效果，再决定是否参与活动、开启盲盒或领取对应服装。

## 行为

- 已开放且当前性别有 Sprite：未拥有时显示「预览」。
- 点击「预览」只替换角色管理面板的大预览 Sprite。
- 不修改 `state.avatar.outfit`。
- 不修改 `state.wardrobe.outfits`。
- 不触发 `saveState()`，因此不会写 localStorage／Supabase。
- 农场场景中的角色保持当前正式穿着。
- 当前正式穿着卡片在预览期间显示「返回当前」。
- 关闭角色面板会清除临时预览状态。
- 未开放或当前性别没有 Sprite 的造型仍显示「尚未开放」。

## 后端

无数据库结构变化，不需要新增 migration。
