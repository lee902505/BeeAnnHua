# V0.18.2 — 中秋限定时装 #5002

## 内容

`#5002 outfit.mid_autumn` 从预留状态正式开放，作为第一套可通过 Item ID 取得并在衣橱手动套用的限定时装。

### Sprite 资产

- `images/farm/avatar/mid-autumn-male.png`
- `images/farm/avatar/mid-autumn-female.png`
- 1024×2048 PNG / RGBA
- 2×4 / 8 Frame
- 每格 512×512
- 角色水平中心 X=256
- 脚底／衣摆基准 Y=467
- 视觉高度约 417px

原始 AI 图没有直接按整张图片平均切割，而是先识别 8 个完整人物，再逐格清理、缩放与重新定位，因此不会把上一格脚底或下一格头顶带入 Frame。

## 玩家流程

1. GM 邮件加入 `#5002 中秋节造型 ×1`。
2. 玩家领取附件。
3. 后端写入 `state.wardrobe.outfits.mid_autumn = true`。
4. 衣橱从「未拥有」变成「套用」。
5. 玩家点击「套用」，写入 `state.avatar.outfit = "mid_autumn"`。
6. 农场实景与角色面板立即使用对应性别的中秋 Sprite。
7. 重新整理／跨装置同步后仍保留拥有权与目前穿着。

领取服装不会自动强制换装。男女玩家共用同一个时装 Item ID 与拥有权。
