# V0.18.3 — 万圣节 / 圣诞节限定时装

## 新开放 Item ID

- `#5003 outfit.halloween`：万圣节造型
- `#5004 outfit.christmas`：圣诞造型

两套均提供男 / 女 Sprite，并沿用衣橱永久拥有权与手动「套用」机制。
未拥有玩家仍可在「我的角色」中预览；预览不会写入存档或改变农场实景角色。

## Sprite 规格

所有正式素材维持：

- 1024×2048 PNG / 真透明 Alpha
- 2×4 / 8 Frame / 每格 512×512
- 水平中心 X=256
- 脚底 Anchor Y=467
- 一般造型视觉高度约 417px

万圣节男性因高礼帽保留约 452px 总高度，但脚底 Anchor 不变，避免压缩身体比例。
圣诞男女均按 4+4 原始生成图逐角色组件抽取，再重新排列；不会把相邻角色的头、脚或衣摆裁入单格。

## SQL

在 027、028 已执行的情况下，只需执行：

`supabase/migrations/20260928_029_halloween_christmas_outfits.sql`

029 会将 #5003 与 #5004 的 `mail_enabled` 开启，GM / 系统邮件附件即可发放，数量固定为 1。
