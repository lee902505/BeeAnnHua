## 存档结构

```json
{
  "pets": {
    "owned": { "ya_ya": true },
    "active": "ya_ya"
  }
}
```

`owned` 表示永久收藏；`active` 只表示目前跟随。未拥有的宠物可在角色页面预览，但不能保存为跟随宠物。
