## 上线步骤

1. 确认 `20260923_003_farm_cloud_save.sql` 已执行。
2. 确认 `20260923_004_farm_rankings_friends.sql` 已执行。
3. Supabase → SQL Editor → New Query。
4. 贴入 `supabase/migrations/20260923_005_farm_friend_visits.sql` 全部内容。
5. **Ctrl+A 全选后按 Run**；成功应显示 `Success. No rows returned`。
6. 上传 V0.13.2 到 GitHub Pages 并重新整理农场。
7. 好友列表中的已接受好友会出现「拜访农场」按钮；排行榜中的好友也可直接拜访。

## 安全说明

`farm_saves` 仍由 RLS 保护，好友无法直接读取整份私人存档。`get_friend_farm` 是 SECURITY DEFINER RPC，会先验证 `auth.uid()` 与目标玩家确实为已接受好友，再只返回显示拜访画面所需的姓名、性别、等级、金币以及经过裁剪的 20 格作物状态。背包、任务、历史记录等不会返回。

目前等级与金币仍来自客户端农场存档，所以排行榜仍属于多人 Beta；偷菜阶段会继续把关键经济操作迁移到服务器端验证。
