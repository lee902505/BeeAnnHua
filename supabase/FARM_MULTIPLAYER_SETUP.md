# 星辰农场多人系统接回指南（V0.13.1）

V0.13.1 开放真实 Supabase 等级榜、金币榜与好友申请 / 接受 / 删除。

## 上线步骤

1. 先确认 V0.13.0 的 `20260923_003_farm_cloud_save.sql` 已成功执行。
2. 在 Supabase → SQL Editor → New Query 打开新查询。
3. 将 `supabase/migrations/20260923_004_farm_rankings_friends.sql` 全部贴入。
4. **Ctrl+A 全选 SQL 后按 Run**。成功时应显示 `Success. No rows returned`。
5. 上传 V0.13.1 到 GitHub Pages 并重新整理农场。
6. 打开「排行榜」：应看到真实拥有云端农场与玩家名称的用户。
7. 在排行榜点击 `＋ 好友`。另一个账号打开「好友」后可接受或忽略。

## 当前开放

- 等级榜：按农场等级排序，同等级再比较金币。
- 金币榜：按金币排序，同金币再比较等级。
- 排行榜直接发送好友申请。
- 双方同时申请会自动成为好友。
- 好友页可接受、忽略、取消申请及删除好友。
- 好友数量会同步到农场任务（1 / 5 / 10 位好友）。

## 尚未开放

- 拜访好友农场。
- 偷菜。
- 偷菜历史。

这些操作需要下一阶段的服务器端收成 / 防重复偷取验证。

## 安全说明

`farm_saves` 仍然是每位用户自己的 RLS 私人存档。排行榜通过 SECURITY DEFINER RPC 只返回玩家名称、性别、等级与金币，不会公开背包、农地详情、历史记录等私人存档。好友表不开放前端直接读写，申请 / 接受 / 删除均通过验证 `auth.uid()` 的 RPC。

目前等级与金币仍源自 V0.13.0 的客户端农场存档，因此排行榜属于多人 Beta；等偷菜阶段把关键经济操作迁移到服务器验证后，再升级为防作弊正式排行。
